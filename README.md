**MeriToken** (`美誉值`, measured in `μ` / `Merit Unit`) is the strictly non-monetary measure of real social contribution on **GMChain** (`公誉链`) within the **iFay** ecosystem—never cashable, never speculative, and never transferable. This repository defines the architectural blueprint for off-chain `MeriToken` citation handles (`mtk_`), three-tier selective disclosure, and revocation-ripple privacy guarantees for **Human Prime** (`人类原型`) and **Fay** (`Fay = iFay + coFay`) subjects.
