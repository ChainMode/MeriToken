# 01 MeriToken 概観

> 概要：本編はブループリント主線の起点であり、ifay 体系における MeriToken の位置づけ、ならびに ifay 全体の議論から MeriToken を独立した一つのプロジェクトとして切り出した二つの理由——新たな社会の「契約部品」および「社会関係コネクタ」としての役割——を提示する。後続の 02–06 編はいずれも本編で定義する位置づけの上に成り立つ。

## 背景

ブループリントが論じる「MeriToken」は、いま一つの汎用ポイントや貢献度の記帳ツールではなく、ifay が構想する「新たな社会」の運用環境におけるインフラ的存在である。MeriToken は二つの異なる方向から同時に基礎的役割を担う。制度層では「契約部品」の形をとり、個人と組織の間の約束と履行に関与する。関係層では「社会関係コネクタ」の形をとり、分散した個人の貢献、協働の記録、社会的評価を一つに編み上げる。

この二方向は並列する二本の事業ラインではなく、同一の資産が異なる抽象層で結ぶ二つの像である。本ブループリントが MeriToken を主線の独立したテーマとして取り上げる理由は、二つの像の間に無視できない引き合いがあるからだ。制度の厳密性が高まる際にそれが関係層の柔軟性を呑み込んではならず、関係層の豊かさが増大する際に契約層の証明可能性を揺るがしてはならない。MeriToken の位置づけと独立して一つのプロジェクトとした理由を先に明確にしておくことで、後続の 02–06 編に共通の出発点が与えられる。

## 核心内容

### MeriToken と GMC の従属関係

MeriToken は単独で稼働する資産プロトコルではなく、`GMC`（Global Merit Chain）という上位体系下の具体的な記帳対象の一種である。`GMC` はグローバルなチェーン記帳、主体間の検証可能性、最終的整合性の保証を提供する。MeriToken はその上で「貢献—評価—参照」という具体的な意味論を担う。

この従属関係は次の三つの帰結を直接導く：

- **データ基盤の一貫性**：MeriToken の所有権変更、参照記録、撤回および更新はすべて `GMC` のチェーン的意味論に従い、別途独立した台帳を起こさない。これにより台帳をまたぐ照合コストを回避できる。
- **ライフサイクルの外部化**：MeriToken は必ずしも個人主体の生涯と歩調を揃えるわけではない。`GMC` 内部における可視性、参照可能性、累積可能性は上位ルールに従って段階的に解放または回収でき、MeriToken 自体の定義を改める必要はない。
- **解釈権の外延**：新たな社会における MeriToken の具体的意味は、上位体系の進化に応じて調整される。本ブループリントは「全体フレームワーク / `phase` 進化」等のさらに上位のテーマを ifay.ai 公式ドキュメント（詳細は [07-related-projects.md](./07-related-projects.md)）に委ね、リポジトリ内で再述しない方針をとる。

MeriToken と `GMC` の関係を明示する目的は、読者が MeriToken を孤立した発明概念として理解することを避けるためである。それは上位体系における「具体的記帳対象」という層の落とし所であり、後続のあらゆる技術的・社会的含意を論じるための共通の出発点でもある。

### 独立して一つのプロジェクトとした二つの理由

データ上は `GMC` に従属するものの、本リポジトリは MeriToken を ifay の全体議論から切り出して独立したブループリントとすることを選んだ。理由は、MeriToken が新たな社会において同時に二種類の基礎的役割を担い、いずれもが単独で研究対象として成立しうる広がりを持つからである。両方の役割を `GMC` の全体議論にまとめると、それぞれの境界が曖昧になる。分けて論じることで、新たな社会における MeriToken の二重の意義をより正確に描き出せる。

#### 新たな社会の契約部品として

第一の理由は制度層に由来する。MeriToken は新たな社会において「自分が何をしたか、誰に対して責任を負うか、誰が見届けたか」の証明可能な記録として参照されうる。したがって本来的に「契約部品」としての役割を担う：

- **約束—履行の証明可能なビット**：主体間の協働において、MeriToken の生成過程それ自体が「貢献が見届けられ、評価され、計上される」という最小単位であり、約束と履行の証明可能なビットとして機能する。事後に第三者が主観的に裁定するのではない。
- **粗粒度の信用に代わる細粒度**：従来の社会で信用スコア、評判、人情等の粗粒度の対象に担わされていた「信頼の供給」は、新たな社会において一連の細粒度・追跡可能・検証可能な MeriToken エントリへと分解されうる。これにより制度論理は「全体としての評判」から「具体的な記録」へと移行する。
- **`credential` との境界**：MeriToken は「何をしたか」の証明可能な記録であり、「自分が誰か、何の権属を持つか」という身元と権属の資格情報ではない。後者は `credential` が担う。両者の境界と対応位置づけは [05-meritoken-credential.md](./05-meritoken-credential.md) で個別に展開しているため、本編では繰り返さない。

MeriToken を契約部品として捉えることの肝は、制度ルールが中央集権的な信用スコアリング機械に依存せず、「契約成立、履行発生、違反の追跡可能性」という三つの事実をそれぞれ具体的な MeriToken 記録に落とし込む点にある。これにより契約は文書上の約束ではなく、構造化され、参照可能で、監査可能な対象となる。

#### 新たな社会の社会関係コネクタとして

第二の理由は関係層に由来する。同一の MeriToken エントリは、契約部品の役割を担うだけでなく、分散した主体を結びつける社会関係のノードでもある：

- **関係グラフの最小辺**：すべての MeriToken 記録には「貢献者—評価者—被サービス対象」という多者関係が含まれており、これら三者関係が自然に新たな社会の関係グラフを構成する。グラフ全体は中心ノードによる維持を必要とせず、各 MeriToken エントリの局所関係が組み合わさることで成立する。
- **主体タイプを横断する接続**：コネクタは主体の形態を区別しない。個人主体同士、個人主体と `Fay` 主体、`Fay` 主体相互の間で、いずれも MeriToken の参照関係を通じて安定した協働の連鎖を形成しうる。`Fay` 主体がどのように MeriToken を参照するかの詳細は [04-meritoken-usage.md](./04-meritoken-usage.md) で詳述する。
- **見知らぬ関係から馴染みの関係への移行経路**：MeriToken は「すでに形成された関係」の記録であるだけでなく、「未だ形成されていない関係」が参照しうる入り口でもある。見知らぬ主体は、相手の既存の MeriToken エントリを参照することで初期的な信頼を形成し、本回の協働で新たに生成される MeriToken エントリによりその協働を沈殿させる。これにより、新たな社会における社会関係は見知らぬ状態から馴染みへと移行する構造化された経路を得る。

MeriToken を社会関係コネクタとして捉えることの肝は、社会関係が外部プラットフォームのアルゴリズム推薦やブラックボックス評価に依存せず、「具体的な協働、具体的な見届け、具体的な参照」というローカルな生成メカニズムへと回帰する点にある。

## 用語脚注

本書に登場する `Reserved_Term`：

- **GMC**：Global Merit Chain、MeriToken の上位体系。詳細は [glossary.md](./glossary.md) を参照。
- **Fay**：非個人主体の MeriToken 参照者。詳細は [glossary.md](./glossary.md) を参照。
- **credential**：個人または `Fay` 主体の身元と権属を裏付ける資格情報。詳細は [glossary.md](./glossary.md) を参照。
- **ifay**：プロジェクト体系の名称。詳細は [glossary.md](./glossary.md) を参照。
- **agent**：従来の LLM 体系下のエージェント。詳細は [glossary.md](./glossary.md) を参照。
- **phase**：ブループリントにおける進化段階の番号。詳細は [glossary.md](./glossary.md) を参照。

MeriToken の中国語主称呼は `zh-CN` と `zh-TW` のブループリント本文においてのみ MeriToken の通常呼称として用いられる。詳細は [glossary.md](./glossary.md) の `Localized_Term` 節を参照。
