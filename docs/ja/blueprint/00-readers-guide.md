# 00 読者ガイド

> 本書はブループリントの入口である。本リポジトリのブループリントが据える執筆主軸、想定読者像、推奨される読み順を示し、読者を主線文書（01–06）へ橋渡しする。

![ifay タイトルバナー](../../zh-CN/blueprint/illustration/ifay-title-banner.png)

## 背景

本リポジトリのブループリントは **MeriToken** の深掘り分析を主軸に据えている。MeriToken は新たな社会において「契約部品」と「社会関係コネクタ」という二つの基礎的役割を担い、MeriToken をめぐる議論が本リポジトリのブループリント文書群の内容主軸を構成する。

ifay 体系、GMC、Fay、agent、phase 等のテーマは、MeriToken 分析に必要となる支援的背景として位置づける。MeriToken の論述上不可欠な範囲においてのみ最小限の位置づけ説明を与え、ifay.ai 上の対応する公式ドキュメントページへ外部リンクで読者を誘導する。本リポジトリ内ではこれら上流・周辺テーマに対する長文の解説は行わず、MeriToken の主軸を曇らせない。

本ブループリントが想定する読者像は次のとおり：

- MeriToken の技術原理、社会的含意、応用シーンを体系的に把握したい研究者、執筆者、協働者；
- ifay 体系の基礎概念に既に触れており、新たな社会における MeriToken の具体的役割を実践面で深掘りしたい読者；
- 多言語版のブループリント文書を執筆ないし翻訳する必要がある翻訳者および保守担当者。

## 核心内容

### ブループリント主軸：MeriToken

ブループリントの本体（01–06）は、次の順序で MeriToken の深掘り分析を展開する：

- **概観（01）**：MeriToken と GMC の従属関係。MeriToken を独立して一つのプロジェクトとして抽出した二つの理由——新たな社会の契約部品としての役割、そして新たな社会の社会関係コネクタとしての役割。
- **技術原理（02）**：MeriToken の暗号化、保管、取得、プライバシー保証、所有権と使用権の保証。
- **社会的含意（03）**：社会関係、政治論理、経済構造、個人成長へのマッピング、ならびに「個人の貢献と社会的発言権」の写像担体としての MeriToken の意味。
- **参照と応用（04）**：個人主体と Fay 主体という二種類の参照者の参照方法および典型的な応用シーン。
- **credential との関係（05）**：credential と MeriToken の役割定位、境界、対応位置づけ。
- **発展テーマ（06）**：主体間協働における高密度利用、ローリングシーン等の発展事例。

### 読み順の提案

番号順に通読することを推奨する：`01 → 02 → 03 → 04 → 05 → 06`。時間が限られている場合や目的が具体的な場合は、次の分岐ルートも参考になる：

- **技術実装に関心がある読者**：`01 → 02 → 05 → 06`。まず MeriToken の基本的な位置づけを押さえ、次に暗号化・保管・取得のクローズドループと credential 境界を深く掘る。
- **社会的・制度的含意に関心がある読者**：`01 → 03 → 04 → 06`。まず MeriToken の全体的位置づけを理解し、次に社会的含意と参照・応用へ進む。
- **他者に MeriToken を解説する必要がある読者**：`01 → 04 → 03`。先に「何であるか、誰が使うのか」を伝え、続いて「なぜそのように設計されているか」を補う。

`07-related-projects.md` は本ブループリントと上流テーマを接続するインタフェース文書であり、補助資料として必要に応じて参照する位置づけにある。主線の読み順には含まれない。

### 上流・周辺テーマとの関係

ifay、GMC、Fay、agent、phase 等の上流・周辺テーマは、[07-related-projects.md](./07-related-projects.md) において「必要最小限の位置づけ説明 + 外部リンク一覧」という形式に集約し、ifay.ai 上の対応する公式ドキュメントページへ読者を誘導する。本リポジトリのブループリント自体はこれらのテーマに対して長文の解説を行わず、MeriToken という主軸の執筆密度を保つ。

これらの上流概念に未だ接していない場合は、まず [07-related-projects.md](./07-related-projects.md) の外部リンクから素早く背景を構築し、その上で主線の 01 へ戻ることを推奨する。

## 用語脚注

本書に登場する `Reserved_Term`：

- **ifay**：プロジェクト体系の名称。詳細は [glossary.md](./glossary.md) を参照。
- **GMC**：Global Merit Chain、MeriToken の上位体系。詳細は [glossary.md](./glossary.md) を参照。
- **Fay**：非個人主体の MeriToken 参照者。詳細は [glossary.md](./glossary.md) を参照。
- **agent**：従来の LLM 体系下のエージェント。詳細は [glossary.md](./glossary.md) を参照。
- **phase**：ブループリントにおける進化段階の番号。詳細は [glossary.md](./glossary.md) を参照。
- **credential**：個人または Fay 主体の身元と権属を裏付ける資格情報。詳細は [glossary.md](./glossary.md) を参照。

MeriToken の中国語主称呼は `zh-CN` と `zh-TW` のブループリント本文においてのみ当該概念の通常呼称として用いられる。詳細は [glossary.md](./glossary.md) の `Localized_Term` 節を参照。
