# 07 ifay 体系との関係

> 本書は「必要最小限の位置づけ説明 + 公式ドキュメントへの外部リンク一覧」という形式で、ifay 体系内のいくつかの上流テーマと MeriToken ブループリントの関係を集約し、本リポジトリ内でこれら上流テーマに対する MeriToken の文脈を超えた長文の解説を行わないようにする。

## 背景

本リポジトリのブループリントは MeriToken の深掘り分析を主軸とする。ifay、GMC、Fay、agent、phase、全体フレームワーク等のテーマは、MeriToken の分析に必要となる支援的背景として位置づけられ、本リポジトリの執筆目標ではない。

保守コストとバージョン漂流を避けるため、本ブループリントはリポジトリ内でこれら上流テーマに長い叙述を加えない。各テーマには MeriToken と関連する必要最小限の位置づけ説明だけを与え、続いて ifay.ai 上の対応する公式ドキュメントページへの外部リンクで読者を上流プロジェクトの権威ある叙述へと誘導する。

ifay 体系に初めて触れる読者には、本書を「外部リンクの入口ページ」として用いることを推奨する。まず公式ドキュメント外部リンク一覧のリンクから素早く上流の背景を構築し、その上で [01-meritoken-overview.md](./01-meritoken-overview.md) に戻って主線へ入る。

## 本ブループリントとの関係

下記の上流用語は本ブループリント内で「最小限の説明」として登場し、MeriToken との最小の接点は次のとおり：

- **ifay**：プロジェクト体系の名称。MeriToken が依拠する全体的な技術および社会の運用環境である。本ブループリントは ifay 体系自体を展開せず、MeriToken の運用環境を述べる際に必要に応じて参照するに留める。
- **GMC**：Global Merit Chain。MeriToken の上位体系である。本ブループリントは [01-meritoken-overview.md](./01-meritoken-overview.md) で MeriToken と GMC の従属関係を述べるが、GMC の全体設計は展開しない。
- **Fay**：ifay 体系内で「MeriToken を参照する」役割を担う非個人主体。個人主体と並ぶ MeriToken の二種の参照者の一方である。本ブループリントは [04-meritoken-usage.md](./04-meritoken-usage.md) で Fay 主体の参照方法と応用シーンを独立に論じる。
- **agent**：従来の LLM 体系下で自律的にタスクを実行するプログラム実体。ifay パラダイムにおいて個人主体 / Fay 主体と対照をなす。本ブループリントは agent と ifay パラダイムの差異の議論には踏み込まず、外部リンクで権威ある定義の入口を提供するに留める。
- **phase**：ブループリントが属するプロジェクトの進化段階の番号。具体的な段階の意味論、タイムライン、マイルストーンは ifay.ai のドキュメントが保守し、本リポジトリでは再述しない。
- **全体フレームワーク**：ifay プロジェクトの全体的なアーキテクチャと各コンポーネントの相互作用の関係。本リポジトリのブループリントは MeriToken というコンポーネントに焦点を当て、全体フレームワークについては ifay.ai 上の対応する公式ドキュメントページに直接アクセスされたい。

## 公式ドキュメント外部リンク一覧

下表は本ブループリントが必要とする最小限の外部リンクの集合を示す。リンクの形式は「ifay.ai 上の対応する公式ドキュメントページに向ける」ことに固定され、具体的な URL は設計層で確定済みであり、`ifay.ai` 以外のドメインへの差替えは認められない。

| 上流用語 | 本ブループリントにおける最小限の説明 | Upstream_Project_Doc_Link |
|----------|--------------------------------------|---------------------------|
| ifay     | MeriToken が依拠する全体的なプロジェクト体系 | https://ifay.ai/docs/ifay |
| GMC      | MeriToken の上位体系（Global Merit Chain） | https://ifay.ai/docs/gmc |
| Fay      | 非個人主体の MeriToken 参照者、個人主体と並ぶ | https://ifay.ai/docs/fay |

phase、全体フレームワーク等のその他の上流テーマについては、ifay.ai サイト内に専用ページが用意されており、読者は必要に応じてサイトのナビゲーションから検索しアクセスされたい。本ブループリントはリンクの漂流を避けるため、これらのリンクをこの一覧に固定化しない。

## 用語脚注

本書に登場する `Reserved_Term`：

- **ifay**：プロジェクト体系の名称。詳細は [glossary.md](./glossary.md) を参照。
- **GMC**：Global Merit Chain、MeriToken の上位体系。詳細は [glossary.md](./glossary.md) を参照。
- **Fay**：非個人主体の MeriToken 参照者。詳細は [glossary.md](./glossary.md) を参照。
- **agent**：従来の LLM 体系下のエージェント。詳細は [glossary.md](./glossary.md) を参照。
- **phase**：ブループリントにおける進化段階の番号。詳細は [glossary.md](./glossary.md) を参照。

MeriToken の中国語主称呼は `zh-CN` と `zh-TW` のブループリント本文においてのみ MeriToken の通常呼称として用いられる。詳細は [glossary.md](./glossary.md) の `Localized_Term` 節を参照。
