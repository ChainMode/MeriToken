# 07 Связь с системой ifay

> Этот документ в форме «минимально необходимых позиционных пометок + список внешних ссылок, указывающих на страницы официальной документации» сводит связь между несколькими вышестоящими темами в системе ifay и чертежом MeriToken, избегая разворачивания вышестоящих тем внутри этого репозитория.

## Предпосылки

Чертёж этого репозитория берёт за главную ось углублённый анализ MeriToken. Темы вроде ifay, GMC, Fay, agent, phase и общей архитектуры позиционируются как поддерживающий фон, необходимый для анализа MeriToken, а не как писательская цель этого репозитория.

Чтобы избежать затрат на сопровождение и расхождения версий, этот чертёж не разворачивает развёрнутые повествования об этих вышестоящих темах внутри репозитория. По каждой теме приводятся только минимально необходимые позиционные пометки, связанные с MeriToken, после чего читатель направляется по внешним ссылкам на соответствующую страницу официальной документации на ifay.ai, где живёт авторитетное повествование вышестоящего проекта.

Читателям, впервые сталкивающимся с системой ifay, рекомендуется использовать этот документ как «страницу входа во внешние ссылки»: сначала сформировать вышестоящий фон, перейдя по ссылкам в списке внешних ссылок официальной документации, а затем вернуться к [01-meritoken-overview.md](./01-meritoken-overview.md), чтобы войти в основную линию.

## Связь с этим чертежом

Каждый вышестоящий термин ниже появляется в этом чертеже в форме «минимальной пометки», и его минимальная связь с MeriToken изложена так:

- **ifay**: название проектной системы; общая техническая и социальная операционная среда, от которой зависит MeriToken. Этот чертёж не разворачивает саму систему ifay и обращается к ней лишь по мере необходимости при описании операционной среды MeriToken.
- **GMC**: Global Merit Chain — вышестоящая система, которой принадлежит MeriToken. Этот чертёж объясняет подчинённость MeriToken системе GMC в [01-meritoken-overview.md](./01-meritoken-overview.md) и не разворачивает общую конструкцию GMC.
- **Fay**: неличный субъект внутри системы ifay, на котором лежит обязанность «обращаться к MeriToken»; вместе с личными субъектами образует две категории субъектов, обращающихся к MeriToken. Этот чертёж разбирает способы обращения и сценарии применения субъектов Fay отдельно в [04-meritoken-usage.md](./04-meritoken-usage.md).
- **agent**: программная сущность в традиционных LLM-фреймворках, автономно выполняющая задачи; в парадигме ifay agent даёт контраст с личным субъектом и субъектом Fay. Этот чертёж не разворачивает обсуждение различий между agent и парадигмой ifay; он лишь предоставляет вход к авторитетным определениям через внешние ссылки.
- **phase**: порядковый номер этапа развития проекта, к которому принадлежит чертёж. Конкретная семантика этапа, временная шкала и вехи поддерживаются документацией ifay.ai; этот репозиторий их не пересказывает.
- **Общая архитектура**: общая архитектура проекта ifay и взаимодействие между его компонентами. Чертёж этого репозитория сосредотачивается на MeriToken как на одном из компонентов; за общей архитектурой обращайтесь напрямую к соответствующей странице официальной документации на ifay.ai.

## Сноски о терминах

Появляющиеся в этом документе `Reserved_Term`:

- **GMC**: Global Merit Chain — вышестоящая система, которой принадлежит MeriToken; см. [glossary.md](./glossary.md).
- **Fay**: неличный субъект, обращающийся к MeriToken; см. [glossary.md](./glossary.md).
- **agent**: сущность agent в традиционных LLM-фреймворках; см. [glossary.md](./glossary.md).
- **phase**: порядковый номер этапа развития в чертеже; см. [glossary.md](./glossary.md).

Основная китайская форма MeriToken используется как обычное обозначение MeriToken только в основном тексте чертежей `zh-CN` и `zh-TW`. Правила локализации MeriToken по языкам см. в разделе `Localized_Term` в [glossary.md](./glossary.md).
