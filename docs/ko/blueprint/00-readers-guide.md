# 00 독자 가이드

> 본 문서는 블루프린트의 진입점이다. 본 저장소 블루프린트가 따르는 집필 주축, 독자 상정, 권장 읽기 경로를 설명하고 독자를 주선 문서 (01–06) 로 안내한다.

![ifay 타이틀 배너](../../zh-CN/blueprint/illustration/ifay-title-banner.png)

## 배경

본 저장소의 블루프린트는 **MeriToken** 의 심층 분석을 중심축으로 전개된다. MeriToken 은 새로운 사회에서 “계약 부품”과 “사회 관계 커넥터”라는 두 가지 기초적 역할을 담당하며, MeriToken 을 둘러싼 논의가 본 저장소 블루프린트 문서 군의 내용 주축을 이룬다.

ifay 체계, GMC, Fay, agent, phase 등의 주제는 MeriToken 분석에 필요한 보조 배경으로 자리매김한다. MeriToken 의 논술상 불가피한 범위에서만 최소한의 위치 설명을 제공하고, ifay.ai 상의 해당 공식 문서 페이지로 외부 링크를 통해 독자를 안내한다. 본 저장소 안에서는 이러한 상위·주변 주제에 대한 장문의 해설을 다루지 않으며, MeriToken 이라는 주축의 집필 밀도를 흐리지 않도록 한다.

본 블루프린트가 상정하는 독자상은 다음과 같다.

- MeriToken 의 기술 원리, 사회적 함의, 응용 시나리오를 체계적으로 파악하고자 하는 연구자, 집필자, 협업자;
- ifay 체계의 기초 개념을 이미 접한 독자로서, 새로운 사회에서 MeriToken 의 구체적 역할을 실천 측면에서 더 깊이 살펴보고자 하는 독자;
- 다국어판 블루프린트 문서를 집필하거나 번역해야 하는 번역자 및 유지보수 담당자.

## 핵심 내용

### 블루프린트 주축: MeriToken

블루프린트 본체 (01–06) 는 다음과 같은 순서로 MeriToken 의 심층 분석을 전개한다.

- **개관 (01)**: MeriToken 과 GMC 의 종속 관계. MeriToken 을 독립적인 하나의 프로젝트로 추출한 두 가지 이유 — 새로운 사회의 계약 부품으로서의 역할, 그리고 새로운 사회의 사회 관계 커넥터로서의 역할.
- **기술 원리 (02)**: MeriToken 의 암호화, 저장, 취득, 프라이버시 보장, 소유권과 사용권의 보장.
- **사회적 함의 (03)**: 사회 관계, 정치 논리, 경제 구조, 개인 성장 매핑, 그리고 “개인의 기여와 사회적 발언권” 의 사상 매개체로서의 MeriToken 의 의미.
- **참조와 응용 (04)**: 개인 주체와 Fay 주체라는 두 가지 참조자의 참조 방식과 전형적 응용 시나리오.
- **credential 과의 관계 (05)**: credential 과 MeriToken 의 역할 정위, 경계, 대응 위치.
- **심화 주제 (06)**: 주체 간 협업에서의 고밀도 사용, 롤링 시나리오 등의 확장 사례.

### 읽기 경로 제안

번호 순으로 통독하는 것을 권장한다: `01 → 02 → 03 → 04 → 05 → 06`. 시간이 한정되어 있거나 목표가 보다 구체적인 경우에는 다음의 분기 경로도 참고할 수 있다.

- **기술 구현에 관심이 있는 독자**: `01 → 02 → 05 → 06`. 먼저 MeriToken 의 기본 정위를 잡고, 그다음 암호화·저장·취득 폐쇄 루프와 credential 경계를 깊이 파고든다.
- **사회적·제도적 함의에 관심이 있는 독자**: `01 → 03 → 04 → 06`. 먼저 MeriToken 의 전체적 정위를 이해한 뒤, 사회적 함의와 참조·응용으로 나아간다.
- **다른 사람에게 MeriToken 을 설명해야 하는 독자**: `01 → 04 → 03`. 먼저 “무엇이고, 누가 사용하는가”를 명확히 하고, 이어서 “왜 그렇게 설계되었는가”를 보충한다.

`07-related-projects.md` 는 본 블루프린트와 상위 주제를 연결하는 인터페이스 문서이며, 보조 자료로서 필요에 따라 참조할 위치에 둔다. 주선의 읽기 경로에는 포함되지 않는다.

### 상위·주변 주제와의 관계

ifay, GMC, Fay, agent, phase 등의 상위·주변 주제는 [07-related-projects.md](./07-related-projects.md) 에서 “최소 필요 위치 설명 + 외부 링크 목록” 형태로 수렴되며, ifay.ai 상의 해당 공식 문서 페이지로 독자를 안내한다. 본 저장소의 블루프린트 자체는 이러한 주제에 대해 장문의 해설을 다루지 않으며 MeriToken 이라는 주축의 집필 밀도를 유지한다.

이러한 상위 개념을 아직 접해 보지 않았다면, 먼저 [07-related-projects.md](./07-related-projects.md) 의 외부 링크에서 빠르게 배경을 구축한 뒤 주선의 01 로 돌아오는 것을 권장한다.
