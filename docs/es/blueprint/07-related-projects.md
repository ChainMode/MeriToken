# 07 Relación con el sistema ifay

> Este documento, en forma de «notas de posicionamiento mínimas necesarias más una lista de enlaces externos a las páginas oficiales de documentación», concentra la relación entre varios temas aguas arriba del sistema ifay y el blueprint de MeriToken, evitando un tratamiento extenso de los temas aguas arriba dentro de este repositorio.

## Antecedentes

El blueprint de este repositorio toma el análisis en profundidad de MeriToken como su eje principal. Los temas como ifay, GMC, Fay, agent, phase y el marco general se posicionan como trasfondo de apoyo necesario para el análisis de MeriToken, no como el objetivo de redacción de este repositorio.

Para evitar el coste de mantenimiento y la deriva de versiones, este blueprint no despliega narrativas extensas de esos temas aguas arriba dentro del repositorio. Para cada tema solo se ofrecen las notas de posicionamiento mínimas necesarias en relación con MeriToken, tras lo cual la lectora o el lector son encaminados mediante enlaces externos a la página oficial correspondiente en ifay.ai, donde reside la narrativa autorizada del proyecto aguas arriba.

Para quienes se encuentran por primera vez con el sistema ifay, recomendamos utilizar este documento como «página de entrada de enlaces externos»: construir primero el trasfondo aguas arriba siguiendo los enlaces de la lista de enlaces externos de la documentación oficial, y volver después a [01-meritoken-overview.md](./01-meritoken-overview.md) para entrar en la línea principal.

## Relación con este blueprint

Cada término aguas arriba que figura a continuación aparece en este blueprint en forma de «nota mínima», con su conexión mínima con MeriToken enunciada como sigue:

- **ifay**: el nombre del sistema del proyecto, el entorno operativo técnico y social global del que depende MeriToken. Este blueprint no despliega el propio sistema ifay y solo lo cita cuando es necesario al describir el entorno operativo de MeriToken.
- **GMC**: Global Merit Chain, el sistema superior al que pertenece MeriToken. Este blueprint explica la subordinación de MeriToken a GMC en [01-meritoken-overview.md](./01-meritoken-overview.md) y no despliega el diseño global de GMC.
- **Fay**: un sujeto no personal dentro del sistema ifay que asume la responsabilidad de «hacer referencia a MeriToken» y que, junto a los sujetos personales, constituye una de las dos clases de referenciadores de MeriToken. Este blueprint trata los modos de referencia y los escenarios de aplicación de los sujetos Fay de manera autónoma en [04-meritoken-usage.md](./04-meritoken-usage.md).
- **agent**: una entidad de programa en los marcos LLM tradicionales que ejecuta tareas de forma autónoma; en el paradigma ifay, el agent ofrece un contraste con el sujeto personal y el sujeto Fay. Este blueprint no despliega la discusión sobre las diferencias entre el agent y el paradigma ifay; solo proporciona la entrada a las definiciones autorizadas mediante enlaces externos.
- **phase**: un número de etapa evolutiva del proyecto al que pertenece el blueprint. La semántica concreta de cada etapa, su línea temporal y sus hitos los mantiene la documentación de ifay.ai; este repositorio no los reformula.
- **Marco general**: la arquitectura global del proyecto ifay y las interacciones entre sus componentes. El blueprint de este repositorio se centra en MeriToken como uno de los componentes; para el marco general, visite directamente la página oficial correspondiente en ifay.ai.
