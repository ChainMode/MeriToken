# 01 美譽值（MeriToken）概覽

> 簡介段：本篇是藍圖主線的起點，給出美譽值在 ifay 體系中的位置，以及它作為獨立專案從 ifay 整體討論中抽出的兩項理由——作為新社會的「契約部件」與「社會關係連接器」。後續 02–06 篇都建立在本篇所定義的位置之上。

## 背景

藍圖所討論的「美譽值（MeriToken）」並非又一種通用積分或貢獻度記帳工具，而是 ifay 設想的「新社會」執行環境中的一項基礎設施。它從兩個不同的方向同時承擔基礎角色：在制度層，它以「契約部件」的形態參與個人與組織之間的承諾與履約；在關係層，它以「社會關係連接器」的形態把分散的個人貢獻、協作記錄與社會評價編織在一起。

這兩個方向並非平行的兩條業務線，而是同一項資產在不同抽象層上的投影。本藍圖把美譽值獨立為一篇主線議題展開，正是因為這兩個投影之間存在不可忽略的相互拉扯：制度嚴密度提升時不能反過來吞噬關係層的彈性，關係層的豐富度增長時不能動搖契約層的可證明性。先把美譽值的位置與獨立成專案的理由講清楚，後續 02–06 篇才有共同的起點。

## 核心內容

### 美譽值（MeriToken）與 GMC 的從屬關係

美譽值不是一項獨立執行的資產協議，而是 `GMC`（Global Merit Chain）這一上位體系下的一類具體記帳對象。`GMC` 給出全域的鏈式記帳、跨主體的可驗證性與最終一致性保證；美譽值則在這之上承擔「貢獻—評價—引用」的具體語義。

這層從屬關係帶來三條直接推論：

- **資料底座一致性**：美譽值的所有權變更、引用記錄、撤銷與更新都遵循 `GMC` 的鏈式語義，不另起一套獨立帳本，避免跨帳本對帳成本。
- **生命週期外延性**：美譽值並不必然伴隨個人主體的整個生命週期；它在 `GMC` 內部的可見性、可引用性、可累計性可以按上位規則分階段開閘或回收，而不需要修改美譽值自身定義。
- **解釋權外推**：美譽值在新社會中的具體含義會隨上位體系的演進調整。本藍圖選擇把「整體框架／`phase` 演進」等更上位的議題留給 ifay.ai 官方文件（詳見 [07-related-projects.md](./07-related-projects.md)），而不在儲存庫內覆述。

把美譽值與 `GMC` 的關係明確寫出來的目的，是避免讀者把美譽值理解成一個孤立的概念發明。它是上位體系在「具體記帳對象」這一層的落點，也是後續討論一切技術與社會含義的共同起點。

### 獨立成專案的兩項理由

雖然美譽值在資料上從屬於 `GMC`，但本儲存庫選擇把它從 ifay 的整體討論裡抽出來獨立成藍圖，原因是它在新社會中同時承擔兩類基礎角色，每一類都足以構成單獨的研究面。把這兩類角色合併到 `GMC` 整體討論裡會模糊各自的邊界；分開來談，反而能更準確地刻畫美譽值在新社會中的雙重意義。

#### 作為新社會的契約部件

第一項理由來自制度層。美譽值在新社會中可被引用為「我做過什麼、對誰負責、由誰見證」的可證明記錄，因此天然承擔「契約部件」的角色：

- **承諾—履約的可證明位**：在跨主體的協作中，美譽值的產生過程本身就是一個「貢獻被見證、被評價、被入帳」的最小單元，它充當承諾與履約的可證明位，而不是事後由第三方主觀仲裁。
- **細粒度替代籠統信用**：傳統社會裡以信用分、口碑、人情等粗粒度對象承載的「信任供給」，在新社會中可以被拆解為一系列細粒度、可追溯、可驗證的美譽值條目；制度邏輯由此從「整體口碑」遷移到「具體記錄」。
- **與 `credential` 的邊界**：美譽值是「做過什麼」的可證明記錄，不是「我是誰、我有什麼權屬」的身分與權屬憑據。後者由 `credential` 承擔。兩者的邊界與對位關係由 [05-meritoken-credential.md](./05-meritoken-credential.md) 單列展開，本篇不重複。

把美譽值視作契約部件的關鍵意義在於：制度規則不再依賴中心化的信用評分機器，而是把「契約成立、履約發生、違約可追溯」三件事各自落到具體的美譽值記錄上。這讓契約不再是文字上的承諾，而是結構化、可被引用、可被審計的對象。

#### 作為新社會的社會關係連接器

第二項理由來自關係層。同一份美譽值條目，除了承擔契約部件的角色，也是把分散主體連接在一起的社會關係節點：

- **關係圖譜的最小邊**：每一條美譽值記錄都包含「貢獻者—評價者—被服務對象」的多方關係，這些三元關係自然地構成新社會的關係圖譜。整張圖譜不必由任何中心節點維護，而是由每一條美譽值條目的局部關係拼合而成。
- **跨主體類型的連接**：連接器不區分主體形態。個人主體之間、個人主體與 `Fay` 主體之間、`Fay` 主體相互之間，都可以透過美譽值的引用關係形成穩定的協作鏈。`Fay` 主體如何引用美譽值的細節由 [04-meritoken-usage.md](./04-meritoken-usage.md) 詳述。
- **從陌生到熟悉的遷移路徑**：美譽值不只是「已經形成的關係」的記錄，也是「尚未形成的關係」可以參考的入口。陌生主體之間透過引用對方既有的美譽值條目達成初步信任，再用新生成的美譽值條目沉澱本次協作；社會關係由此在新社會裡從陌生到熟悉的遷移有了一條結構化的路徑。

把美譽值視作社會關係連接器的關鍵意義在於：社會關係不再依賴外部平台的演算法推薦與黑箱評級，而是回歸到「具體協作、具體見證、具體引用」的本地化生成機制。
