# 00 閱讀指南

> 本文是藍圖的入口。它說明本儲存庫藍圖的寫作主軸、讀者畫像與推薦閱讀路徑，並把讀者引導到主線文件（01–06）。

![ifay 標題橫幅](../../zh-CN/blueprint/illustration/ifay-title-banner.png)

## 背景

本儲存庫的藍圖圍繞 **美譽值（MeriToken）** 的深度分析展開。美譽值在新社會中承擔「契約部件」與「社會關係連接器」兩類基礎角色，是本儲存庫藍圖文件的內容主軸。

ifay 體系、GMC、Fay、agent、phase 等議題,定位為美譽值分析所必需的支撐性背景：僅在美譽值的展開必須涉及時給出最小必要的位置說明，並透過外鏈將讀者引導至 ifay.ai 上對應的官方文件頁，本儲存庫內不再對這些上游／外圍議題做長篇闡述。

本藍圖面向的讀者畫像：

- 希望系統了解美譽值技術原理、社會內涵與應用場景的研究者、寫作者與協作者；
- 已經接觸過 ifay 體系基礎概念，希望進一步了解美譽值在新社會中具體角色的實踐者；
- 需要為多語言版本撰寫或翻譯藍圖文件的譯者與維護者。

## 核心內容

### 藍圖主軸：美譽值（MeriToken）

藍圖主體（01–06）按以下順序展開美譽值的深度分析：

- **概覽（01）**：美譽值與 GMC 的從屬關係；獨立成專案的兩項理由——作為新社會的契約部件、作為新社會的社會關係連接器。
- **技術原理（02）**：加密、儲存、取用、隱私保證、所有權與使用權保證。
- **社會內涵（03）**：社會關係、政治邏輯、經濟結構、個人成長映射，以及美譽值作為「個人貢獻與社會話語權」映射載體的含義。
- **引用與應用（04）**：個人主體與 Fay 主體兩類引用者的引用方式與典型應用場景。
- **credential 關係（05）**：credential 與美譽值的角色定位、邊界與對位關係。
- **進階專題（06）**：跨主體協作中的高密度使用、滾動場景等延伸案例。

### 閱讀路徑建議

推薦按編號順序通讀：`01 → 02 → 03 → 04 → 05 → 06`。如果時間有限或目標更具體，可參考以下分支路徑：

- **關心技術實現**：`01 → 02 → 05 → 06`，先建立美譽值的基本定位，再深入加密／儲存／取用閉環與憑證邊界。
- **關心社會與制度含義**：`01 → 03 → 04 → 06`，先理解美譽值的整體定位，再展開社會內涵與引用應用。
- **需要為他人講解美譽值**：`01 → 04 → 03`，先把「是什麼、誰在用」說清，再補「為什麼這樣設計」。

`07-related-projects.md` 是本藍圖與上游議題的銜接文件，作為補充材料按需查閱，不在主線閱讀路徑上。

### 與上游／外圍議題的關係

ifay、GMC、Fay、agent、phase 等上游／外圍議題，統一由 [07-related-projects.md](./07-related-projects.md) 收斂為「最小必要位置說明 + 外鏈清單」形態，引導讀者前往 ifay.ai 上對應的官方文件頁。本儲存庫藍圖本身不對這些議題做長篇闡述，以保持美譽值這一主軸的寫作密度。

如果你尚未接觸過這些上游概念，建議先前往 [07-related-projects.md](./07-related-projects.md) 中的外鏈快速建立背景，再回到主線閱讀 01。
