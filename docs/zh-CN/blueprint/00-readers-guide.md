# 00 阅读指南

> 本文是蓝图的入口。它说明本仓库蓝图的写作主轴、读者画像与推荐阅读路径，并把读者引导到主线文档（01–06）。

![ifay 标题横幅](./illustration/ifay-title-banner.png)

## 背景

本仓库的蓝图围绕 **美誉值（MeriToken）** 的深度分析展开。美誉值在新社会中承担「契约部件」与「社会关系连接器」两类基础角色，是本仓库蓝图文档的内容主轴。

ifay 体系、GMC、Fay、agent、phase 等议题，定位为美誉值分析所必需的支撑性背景：仅在美誉值的展开必须涉及时给出最小必要的位置说明，并通过外链将读者引导至 ifay.ai 上对应的官方文档页，本仓库内不再对这些上游/外围议题做长篇阐述。

本蓝图面向的读者画像：

- 希望系统了解美誉值技术原理、社会内涵与应用场景的研究者、写作者与协作者；
- 已经接触过 ifay 体系基础概念，希望进一步了解美誉值在新社会中具体角色的实践者；
- 需要为多语言版本撰写或翻译蓝图文档的译者与维护者。

## 核心内容

### 蓝图主轴：美誉值（MeriToken）

蓝图主体（01–06）按以下顺序展开美誉值的深度分析：

- **概览（01）**：美誉值与 GMC 的从属关系；独立成项目的两项理由——作为新社会的契约部件、作为新社会的社会关系连接器。
- **技术原理（02）**：加密、存储、取用、隐私保证、所有权与使用权保证。
- **社会内涵（03）**：社会关系、政治逻辑、经济结构、个人成长映射，以及美誉值作为「个人贡献与社会话语权」映射载体的含义。
- **引用与应用（04）**：个人主体与 Fay 主体两类引用者的引用方式与典型应用场景。
- **credential 关系（05）**：credential 与美誉值的角色定位、边界与对位关系。
- **进阶专题（06）**：跨主体协作中的高密度使用、滚动场景等延伸案例。

### 阅读路径建议

推荐按编号顺序通读：`01 → 02 → 03 → 04 → 05 → 06`。如果时间有限或目标更具体，可参考以下分支路径：

- **关心技术实现**：`01 → 02 → 05 → 06`，先建立美誉值的基本定位，再深入加密/存储/取用闭环与凭证边界。
- **关心社会与制度含义**：`01 → 03 → 04 → 06`，先理解美誉值的整体定位，再展开社会内涵与引用应用。
- **需要为他人讲解美誉值**：`01 → 04 → 03`，先把「是什么、谁在用」讲清，再补「为什么这样设计」。

`07-related-projects.md` 是本蓝图与上游议题的接口文档，作为补充材料按需查阅，不在主线阅读路径上。

### 与上游/外围议题的关系

ifay、GMC、Fay、agent、phase 等上游/外围议题，统一由 [07-related-projects.md](./07-related-projects.md) 收敛为「最小必要位置说明 + 外链清单」形态，引导读者访问 ifay.ai 上对应的官方文档页。本仓库蓝图本身不对这些议题做长篇阐述，以保持美誉值这一主轴的写作密度。

如果你尚未接触过这些上游概念，建议先访问 [07-related-projects.md](./07-related-projects.md) 中的外链快速建立背景，再回到主线阅读 01。
